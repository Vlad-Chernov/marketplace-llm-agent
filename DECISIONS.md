# Журнал решений

Здесь фиксируются архитектурные и продуктовые решения проекта: контекст, варианты, выбранное решение и последствия.

## Требования к журналу

- До завершения проекта должно быть не менее 8 записей.
- Каждая запись содержит дату, контекст, решение, причины и последствия.
- Новая запись добавляется при изменении значимого технического решения.

## Записи

## D-001. Язык пользовательских синтетических данных

**Дата:** 2026-08-14

**Контекст:** Проект имитирует русскоязычный маркетплейс.

**Решение:** Отзывы, описания поставщиков, тексты поддержки и интерфейс пишутся на русском языке. Имена классов, функций, полей, переменных и скрытые технические метки остаются на английском. Бренды, модели, SKU и общепринятые технические аббревиатуры сохраняют исходное написание.

**Причины:** Это делает данные реалистичными и одновременно сохраняет код понятным для международного портфолио.

**Последствия:** Все новые синтетические пользовательские тексты создаются на русском языке.

## D-002. Провайдеры LLM для MVP

**Дата:** 2026-08-14

**Контекст:** MVP требует два бесплатных облачных LLM API с доступом из России, поддержкой русского языка, ограниченными квотами и возможностью структурированного вывода. MacBook Air M2 с 8 ГБ памяти не является основной средой для локальной модели на первом этапе.

**Решение:** Основной провайдер — Groq с моделью `llama-3.3-70b-versatile`. Резервный провайдер — OpenRouter с маршрутом `openrouter/free`. Оба ключа проверены запросом к API моделей: HTTP 200.

**Причины:** Groq даёт более высокие бесплатные лимиты для экспериментов. OpenRouter предоставляет бесплатные модели и совместимый с OpenAI API как резервный путь. Оба варианта не требуют оплаты для начального MVP.

**Ограничения:** Бесплатные лимиты и доступные модели могут меняться. У OpenRouter без пополнения ограниченный дневной лимит. Поддержка структурированного вывода будет отдельно измерена в блоке 2.4.

**Источники:** https://console.groq.com/docs/rate-limits ; https://openrouter.ai/docs/faq ; https://openrouter.ai/docs/guides/routing/model-variants/free
