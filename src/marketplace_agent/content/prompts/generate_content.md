Создай карточку ноутбука только по подтверждённым данным.
Пиши title, bullets, description и keywords на русском языке. Бренды, модели, SKU и технические аббревиатуры оставляй в исходном написании.

Товар:
{product}

Подтверждённые характеристики:
{attributes}

Верни только JSON со следующими полями:
- title: строка;
- bullets: список из 3–5 коротких пунктов;
- description: строка;
- keywords: список ключевых слов;
- used_attributes: объект с ключами только из подтверждённых характеристик.

Не выдумывай факты и не используй характеристики со значением null.
