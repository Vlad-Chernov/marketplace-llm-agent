# Масштабирование синтетических данных

## Цель

Расширить воспроизводимый синтетический корпус до 400 товаров,
4000 отзывов и 500 заказов для трёх категорий: ноутбуки, кроссовки
и чайники. Добавить документы поддержки так, чтобы всего их было 10.

## Каталог

Генератор каталога остаётся одной точкой входа, но собирает товары
из трёх небольших шаблонов категорий. Распределение фиксировано:

- 134 ноутбука со SKU `LAP-...`;
- 133 кроссовка со SKU `SNK-...`;
- 133 чайника со SKU `KTL-...`.

Каждый шаблон заполняет реалистичные значения `true_attributes` для
своей спецификации. Текущие ноутбучные данные и их шум сохраняются
совместимыми с существующими конвейерами.

## Связанные данные

Отзывы и заказы строятся поверх общего каталога: 4000 отзывов и
500 заказов. Каждый отзыв и заказ ссылается на SKU из этих 400 товаров.
Seed остаётся входом генератора, чтобы повторный запуск давал тот же
набор данных.

## Документы поддержки

Существующие документы `returns`, `exchange`, `warranty`, `delivery`
сохраняются. Добавляются шесть: `payment`, `cancellation`,
`order_status`, `laptops`, `sneakers`, `kettles`. Всего — 10 документов.

## Проверки

Тесты проверяют:

- точные количества товаров, отзывов и заказов;
- распределение товаров 134/133/133;
- уникальные SKU с префиксами категорий;
- ссылки отзывов и заказов только на SKU общего каталога;
- наличие десяти документов поддержки.

Полный генератор запускается локально через `make data`; API и токены
для этого не требуются.
