# Privacy NER Design

## Цель

Расширить защиту PII: маскировать ФИО, телефоны, email, номера заказов и адреса до сохранения данных в отзыве, evaluation JSON и JSONL-трассе.

## Компоненты

`privacy.pii` предоставляет `PiiRedactor`.

Он применяет регулярные выражения для телефонов, email, номеров заказов и адресов с явными маркерами. Затем локальная русская NER-модель spaCy распознаёт сущности `PERSON`.

Плейсхолдеры: `[PHONE]`, `[EMAIL]`, `[ORDER]`, `[ADDRESS]`, `[PERSON]`.

## Память

`PiiRedactor` не хранит модель глобально. Он загружает её при начале операции, обрабатывает переданный пакет текстов и освобождает в `close()`. После завершения операции модель не занимает память процесса.

## Потоки данных

Санитайзер применяется перед сохранением текста в:

- `reviews/cleaning.py`;
- `TraceWriter` для строковых и вложенных значений payload;
- `evals/runner.py` для `raw_response` и текстов ошибок.

Если NER недоступен, исходный текст в trace или evaluation JSON не сохраняется: записывается `[REDACTION_UNAVAILABLE]`.

## Проверки

`data/gold/pii_cases.json` содержит 150 ручных случаев: 100 существующих, 40 ФИО и 10 адресов.

Тесты проверяют:

- recall `1.000` на golden-наборе;
- корректные плейсхолдеры;
- отсутствие PII в сохранённом evaluation JSON;
- отсутствие PII в trace JSONL, включая вложенные структуры;
- сохранение текущего поведения очистки отзывов.

## Границы

Решение не использует внешние API и не расходует токены. Компании, города, документы, банковские карты и адреса без явных маркеров не входят в текущий scope.
