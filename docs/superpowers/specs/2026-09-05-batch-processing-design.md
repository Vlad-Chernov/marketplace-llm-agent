# Batch processing design

## Цель

Обрабатывать карточки нескольких товаров через существующий
`run_content_pipeline` с ограничением параллелизма и частоты LLM-вызовов.

## Границы 11.1

Этап добавляет concurrency и rate limiting. Retry, checkpoint/resume,
dead-letter queue и измерение throughput остаются для 11.2–11.4.

## Компоненты

- `BatchProcessor` — получает SKU, товары и запускает обработку.
- `RateLimiter` — общий потокобезопасный ограничитель LLM-запросов.
- `RateLimitedLLMClient` — оборачивает LLM-клиент и запрашивает permit
  перед каждым `chat`.
- `BatchSummary` — результаты, ошибки и длительность выполнения.

## Интерфейс

```python
BatchProcessor.run(
    product_ids: list[str],
    resume: bool = True,
) -> BatchSummary
```

В 11.1 `resume` не меняет результат: checkpoints появятся в 11.3.

## Выполнение

1. Входные SKU должны быть уникальны; повтор — `ValueError`.
2. `ProductRepository` получает товар по каждому SKU.
3. `ThreadPoolExecutor(max_workers=2)` запускает не более двух товаров.
4. Каждый worker создаёт отдельный LLM-клиент через фабрику.
5. Worker запускает текущий `run_content_pipeline(product, llm)`.
6. `RateLimitedLLMClient` использует один общий limiter для всех workers.
7. Результаты возвращаются в порядке входных SKU.

## Rate limiter

- Значение по умолчанию: 30 запросов в минуту.
- Новый запрос стартует не чаще одного раза в 2 секунды.
- Ограничение общее для всех workers и всех LLM-клиентов batch-процесса.
- Лимиты настраиваются через `.env`:
  `BATCH_MAX_WORKERS=2` и `BATCH_LLM_REQUESTS_PER_MINUTE=30`.

## Ошибки

- Неизвестный SKU записывается в `BatchSummary.errors`.
- Ошибка обработки одного товара записывается в `errors`; остальные SKU
  продолжают выполняться.
- В 11.1 ошибки не повторяются автоматически и не сохраняются в очередь.

## Проверка

Unit-тесты без API проверяют:

- не более двух одновременно работающих задач;
- общий лимит запросов для нескольких workers;
- продолжение после ошибки одного SKU;
- порядок результатов по входному списку SKU;
- настройки по умолчанию и из окружения.
