# Review cleaning design

## Цель

Детерминированно подготовить отзывы к кластеризации и LLM-разметке:
очистить текст, замаскировать ПДн, удалить мусор и дубликаты.

## Интерфейс

```python
clean_reviews(reviews: list[Review]) -> ReviewCleaningResult
```

`ReviewCleaningResult` содержит:

- `reviews`: сохранённые отзывы с очищенным текстом;
- `duplicate_review_ids`: ID удалённых точных и почти точных дублей;
- `discarded_review_ids`: ID отброшенных бесполезных отзывов;
- `redacted_review_ids`: ID отзывов, где были замаскированы ПДн.

## Порядок обработки

1. Убрать HTML, нормализовать пробелы и обрезать текст по краям.
2. Маскировать телефоны, email и номера заказов маркерами.
3. Отбросить короткие бесполезные отзывы: `норм`, `ок`, `спасибо`, `хорошо`.
4. Не отбрасывать короткий отзыв, если в нём есть признак дефекта:
   `греется`, `перегрев`, `мерцает`, `клавиш`, `wifi`, `wi-fi`, `батаре`.
5. В пределах одного SKU оставить первый отзыв, удалить точные дубли.
6. Затем удалить почти точные дубли внутри того же SKU при
   `SequenceMatcher.ratio() >= 0.92`.
7. Сохранить порядок исходных отзывов и их скрытые метки.

## Ограничения

- LLM и эмбеддинги не используются.
- Отзывы разных SKU не сравниваются.
- ПДн маскируются, а не становятся причиной удаления полезного отзыва.
- Порог похожести фиксирован и тестируется.

## Проверки

Тесты подтверждают:

- очистку HTML, пробелов и ПДн;
- удаление точного и почти точного дубля;
- сохранение отзыва `греется`;
- удаление отзыва `норм`;
- отсутствие дедупликации между разными SKU.
