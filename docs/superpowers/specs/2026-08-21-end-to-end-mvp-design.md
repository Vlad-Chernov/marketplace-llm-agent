# End-to-End MVP Demo Design

## Goal

Добавить воспроизводимый локальный запуск MVP командами `make data`, `make ingest` и `make demo`.

## Approach

`scripts/demo.py` будет только собирать готовые модули проекта, не содержать бизнес-логику.

Сценарий демонстрации:

1. Берёт товар из SQLite, извлекает его атрибуты, генерирует и проверяет карточку.
2. Берёт отзыв и классифицирует дефект.
3. Отвечает на вопрос покупателя через `SupportAgent`, инструменты и поиск по правилам.

`make demo` запускает этот сценарий с настоящим выбранным LLM-провайдером. Тесты используют `FakeLLMClient`, поэтому не требуют сети и API-ключа.

## Settings

Приложение требует API-ключ только выбранного провайдера:

- `LLM_PROVIDER=groq` → нужен `GROQ_API_KEY`;
- `LLM_PROVIDER=openrouter` → нужен `OPENROUTER_API_KEY`.

## Files

- `scripts/demo.py` — единый демонстрационный сценарий;
- `tests/test_demo.py` — тест запуска с fake-моделью;
- `Makefile` — команда `make demo`;
- `src/marketplace_agent/config.py` — проверка ключа выбранного провайдера;
- `.env.example` — пример настроек;
- `docs/DEMO.md` — реальные команды и ожидаемый результат.
